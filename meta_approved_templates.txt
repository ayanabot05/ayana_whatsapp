# =============================================================================
# WHY NOT WRITE WITHOUT TEMPLATES? EXPLANATION
# =============================================================================

# WhatsApp Rule:
# - Within 24h of user's last message: You can send FREE-FORM text (send_whatsapp)
# - Outside 24h: You MUST use APPROVED TEMPLATE, free-form fails with error:
#   "Failed to send message: Outside allowed window"

# Example:
# Morning: You send check-in at 8am (template, opens 24h window)
# Parent replies at 8:05am (window extended to next day 8:05am)
# 
# Case 1: Safety check at 7pm same day (within 24h) -> free-form WORKS (no template needed)
# Case 2: Parent didn't reply morning, safety check at 7pm next day (outside 24h) -> free-form FAILS, need template
# Case 3: Child warnings at 2pm/10pm - child rarely replies -> always outside 24h -> MUST need template

# Code already handles both:
# - Tries template first (works outside window)
# - If template not found (not approved yet), falls back to free-form (works only within window)
