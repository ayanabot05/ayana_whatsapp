# AYANA – WhatsApp Templates v2 FINAL (bodies + buttons + footer)   ---- Amma / అమ్మ / माँ

Languages: English (`en`), Telugu (`te`), Hindi (`hi`). Names: `ayana_<name>_v2_<lang>`.
Category: **UTILITY** for everything except the love note (Marketing).

## Footer (parent-facing templates with buttons)
Same footer on every template marked "Footer: yes". Footers are plain text, max 60 characters, no variables.

- en: `👇 Tap below or 🎙️ send a voice note`
- te: `👇 కింద ఆప్షన్‌ను నొక్కండి లేదా 🎙️ వాయిస్ నోట్ పంపండి`
- hi: `👇 नीचे दिए गए विकल्प टैप करें या 🎙️ वॉइस नोट भेजें`

Child-facing alerts and notifications have no footer (the voice-note footer would make no sense there).
The longer alternate footer from your notes ("hold mic to send voice note") is over 60 characters in Telugu and Hindi, so it can't be used as a footer.

## Quick reference
- Parent-facing = variable {{1}} is the parent's display name (Amma / Nanna / Papa / Maa etc.).
- Quick-reply buttons carry your wording; max 25 characters each.
- Hindi buttons are gender-neutral ("घर पर हूँ", "सही-सलामत हूँ") because the same template is used for Maa and Papa.
- Variable values must not contain newlines, tabs or 4+ consecutive spaces (sanitize parent reply text in code).

## Authentication (OTP) – `ayana_otp_v2_en / _te / _hi`
Category: AUTHENTICATION. Meta generates the body text itself ("<code> is your verification code") per language; you do not write it.
Create each with: body `add_security_recommendation: true`, footer `code_expiration_minutes: 10`, one button of type OTP (copy code). Footer text for authentication templates is fixed by Meta, so the voice-note footer does not apply.
Authentication is the right category for login/verification codes only. Don't use it for anything else.

## Submission checklist
- Submit via API with `"allow_category_change": false`, so a misclassification returns as a rejection you can see.
- Use the samples above for every variable. Parent-facing samples are names (Amma / అమ్మ / माँ).
- Don't resubmit rejected names; bump to `_v3`.
- Update the template-name map in your code to the `_v2_` names.
- Record WhatsApp opt-in for parent and child at signup.
- Marketing templates (love note) never go to US +1 numbers.
